Design Choices

I built this page around a single accent green pulled from a tennis court, and reused it for the rule under my name, the chart line, and the bars, so every element reads as part of one system instead of competing for attention. The layout is a single centered column with a fixed maximum width, which keeps the text at a comfortable reading length and lets the photos and charts fall into predictable pairs. I paired a serif for headings with a sans-serif for body text to build hierarchy without adding more colors or weights. In both charts I removed the gridlines and legend wherever a single data series made them redundant, so the data is the loudest thing on the page. I also kept all the JavaScript in one block at the bottom of the file and grouped the CSS by section, so the code is as easy to scan as the page.
